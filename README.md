# DEUS DERELICTUS — Avancement

Page publique qui montre l'avancement du développement du mod, mise à jour en direct.

- `progress.json` : les données (pourcentage par domaine, fait / en cours / à faire, journal). Le pourcentage global est la moyenne pondérée des domaines (`weight`).
- `index.html` : la page. Elle relit `progress.json` toutes les minutes et affiche les dernières publications de ce dépôt.

Chaque étape du développement = un commit qui met à jour `progress.json`.

Ce dépôt ne contient **que** l'avancement : pas de code du mod, pas d'histoire, pas de noms.
